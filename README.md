# ClearTalk

เว็บต้นแบบระบบตรวจสอบคำไม่เหมาะสม ใช้ HTML, CSS และ JavaScript แบบไม่ต้องติดตั้งแพ็กเกจ

## เปิดใช้งาน

แนะนำให้เปิดเซิร์ฟเวอร์พร้อมฐานข้อมูลด้วย Python (ไม่ต้องติดตั้งแพ็กเกจเพิ่ม):

```bash
python server.py
```

จากนั้นเปิด `http://127.0.0.1:8000` ในเบราว์เซอร์เพื่อดูหน้าแรกสาธารณะ ผู้เข้าชมเลือกสมัครสมาชิกหรือเข้าสู่ระบบได้ ฐานข้อมูล SQLite จะถูกสร้างอัตโนมัติที่ `data/cleartalk.sqlite3` หากเปิดไฟล์เว็บโดยตรงหรือใช้ Live Server หน้าเว็บจะไม่ได้เชื่อมต่อฐานข้อมูลของ `server.py`

เปิด `http://127.0.0.1:8000/register.html` เพื่อสร้างบัญชีแรก แล้วเข้าสู่ระบบที่ `http://127.0.0.1:8000/login.html` หน้าแอปหลักต้องเข้าสู่ระบบก่อนใช้งาน

### บัญชีผู้ดูแลระบบ

บัญชีที่สมัครผ่านหน้าเว็บจะได้สิทธิ์ผู้ใช้ทั่วไปเสมอ หากต้องการสร้างผู้ดูแลระบบ ให้หยุดเซิร์ฟเวอร์ก่อน แล้วรันคำสั่งนี้ในโฟลเดอร์โปรเจกต์:

```powershell
python server.py --create-admin "ชื่อผู้ดูแล" admin@example.com
```

พิมพ์รหัสผ่านเมื่อ Terminal ถาม (จะไม่แสดงตัวอักษรขณะพิมพ์) จากนั้นเปิดเซิร์ฟเวอร์อีกครั้งด้วย `python server.py` แล้วเข้าสู่ระบบด้วยอีเมลแอดมิน ระบบจะพาไปหน้า `/admin.html` ซึ่งดูรายชื่อบัญชีสมาชิกได้ ส่วนบัญชีผู้ใช้ทั่วไปจะเข้าได้เฉพาะหน้าใช้งาน และ API ตรวจสิทธิ์แอดมินก่อนให้แก้ข้อมูลจัดการคำ

## ความสามารถ

- Dashboard สรุปข้อมูลและรายการตรวจสอบล่าสุด
- หน้าตรวจข้อความ พร้อมตัวเลือกหมวดหมู่และตัวนับอักขระ
- ตรวจคำจากรายการที่ผู้ดูแลเพิ่มไว้ และบันทึกผลลงประวัติ
- มีรายการคำหยาบภาษาไทยเริ่มต้น และตรวจจับคำแม้มีช่องว่าง/เครื่องหมายคั่น
- นำเข้าคำจาก lexicon ของ PyThaiNLP ระดับสูง/กลาง/ต่ำลง SQLite อัตโนมัติเมื่อเริ่มเซิร์ฟเวอร์
- ค้นหาประวัติและกรองตามผลการตรวจ
- เพิ่มคำและเปิด/ปิดคำในหน้าจัดการผู้ดูแล
- ตั้งค่าหมวดหมู่ที่เลือกไว้ล่วงหน้า และดาวน์โหลดข้อมูลเป็น JSON
- เก็บประวัติ คำ และการตั้งค่าไว้ในฐานข้อมูล SQLite เมื่อเปิดผ่าน `server.py`
- สมัครสมาชิก เข้าสู่ระบบ และออกจากระบบ โดยเก็บรหัสผ่านเป็นแฮช

## หน้าเว็บ

- `login.html` และ `register.html` หน้าเข้าสู่ระบบและสมัครสมาชิก
- `dashboard.html` ภาพรวม
- `check.html` ตรวจสอบข้อความ
- `history.html` ประวัติการตรวจสอบ
- `manage-words.html` จัดการคำไม่เหมาะสม
- `settings.html` ตั้งค่าระบบ

- เก็บประวัติและรายการคำไว้ใน localStorage ของเบราว์เซอร์
- รองรับหน้าจอมือถือ

หน้าสมัครและเข้าสู่ระบบแยกไฟล์พร้อม CSS/JavaScript ของตัวเอง ส่วนหน้าแอปที่เหลือมีไฟล์ทางเข้าแยก แต่ยังใช้ layout และเมนูร่วมจาก `index.html`

## ขอบเขตข้อมูล

รุ่นนี้เป็นต้นแบบสำหรับใช้งานในเครื่อง มีบัญชีผู้ใช้และ session ใน SQLite สำหรับเซิร์ฟเวอร์ local ข้อมูลการตรวจและรายการคำใช้ร่วมกันในฐานข้อมูลของเครื่อง ยังไม่มีการแยกข้อมูลตามบัญชีหรือกำหนดสิทธิ์ผู้ดูแล การตรวจสอบใช้การจับคู่คำจากรายการในระบบ ไม่ใช่โมเดล AI และควรพิจารณาบริบทด้วยเสมอ

## ที่มารายการคำหยาบ

ไฟล์ `profanity_th.txt` มาจากคลังคำของ [PyThaiNLP](https://github.com/PyThaiNLP/pythainlp/blob/dev/pythainlp/corpus/profanity_th.txt) ส่วนรายการแบ่งระดับ `swear-words-high.txt`, `swear-words-medium.txt` และ `swear-words-low.txt` มาจาก [PyThaiNLP lexicon-thai](https://github.com/PyThaiNLP/lexicon-thai/tree/master/swear-words) ซึ่งระบุสัญญาอนุญาต CC BY-SA 4.0 ไฟล์ต้นฉบับเก็บอยู่ในโปรเจกต์และนำเข้า SQLite เมื่อเริ่มเซิร์ฟเวอร์ โดยไม่เขียนทับคำที่มีอยู่แล้ว

## ไฟล์

- `index.html` โครงหน้าและสไตล์
- `app.js` การเก็บข้อมูลและตรรกะของแอป
- `server.py` เว็บเซิร์ฟเวอร์และ API สำหรับ SQLite
- `profanity_th.txt` รายการคำหยาบภาษาไทยจาก PyThaiNLP
- `swear-words-high.txt`, `swear-words-medium.txt`, `swear-words-low.txt` รายการคำแบ่งระดับจาก PyThaiNLP lexicon-thai
- `auth.css`, `auth.js` รูปแบบและการทำงานของหน้าสมัคร/เข้าสู่ระบบ
- `data/cleartalk.sqlite3` ฐานข้อมูลที่สร้างเมื่อเริ่มเซิร์ฟเวอร์ครั้งแรก
